## 🌟 Características

- **Diseño Moderno y Profesional**: Interfaz orientada a reclutadores técnicos y clientes, con estética moderna, tipografía cuidada y soporte completo para **Modo Oscuro / Claro** con persistencia local.
- **Barra de Navegación Sticky con Glassmorphism**: Enlaces directos a cada sección con smooth scroll, acceso rápido a descarga de CV en PDF y redes.
- **Hero Section de Alto Impacto**: Terminal de código interactiva (`bio.ts`), métricas clave de impacto y botones de llamada a la acción (CTA).
- **Sobre Mí & Filosofía**: 4 pilares de ingeniería de software (Arquitectura Full Stack, Seguridad & Auditoría, APIs RESTful y Buenas Prácticas).
- **Línea de Tiempo de Experiencia**:
  - *Full Stack Developer* — Hospital Infantil de México Federico Gómez (Angular 19, Node.js, TypeScript, Django).
  - *Auditor del Sistema Informático PREP IEEPCO* — Universidad Autónoma Metropolitana Unidad Iztapalapa (Node.js, Jasmine).
- **Showcase de Proyectos con Filtrado y Modal de Detalles**:
  - Filtros por categoría: *Full Stack*, *Frontend*, *Backend & APIs*, *Auditoría / Sistemas*.
  - Modal interactivo con arquitectura y puntos técnicos clave por proyecto.
- **Matriz de Habilidades con Búsqueda en Tiempo Real**: Filtrado interactivo instantáneo de tecnologías (Frontend, Backend, Bases de Datos, DevOps, Herramientas).
- **Educación Universitaria y Certificaciones Platzi**: Formación académica en la UAM-I y especializaciones técnicas acreditadas.
- **Contacto Interactivo**: Botón de copiado con 1 clic para email con feedback mediante toast (Sonner), enlace directo a WhatsApp y formulario de contacto.

## 🚀 Tecnologías Utilizadas

- **Framework**: [React 18](https://react.dev/) + [Vite 6](https://vitejs.dev/)
- **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Componentes & UI**: [Radix UI](https://www.radix-ui.com/)
- **Iconografía**: [Lucide React](https://lucide.dev/)
- **Notificaciones**: [Sonner](https://sonner.emilkowal.ski/)

## 🛠️ Instalación y Desarrollo Local

1. **Clonar el repositorio e instalar dependencias**:
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo**:
   ```bash
   npm run dev
   ```

3. **Compilar para producción**:
   ```bash
   npm run build
   ```
